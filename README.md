# Автопарк и логистика – CLI система

## Предметная область
Учёт транспортных средств, водителей, маршрутов, рейсов и техобслуживания.

## Структура папок
bin/ – точка входа  
lib/src/domain – модели и валидаторы  
lib/src/data – работа с SQLite  
lib/src/cli – консольный интерфейс  

## Слои
- **domain** – чистые модели и правила. Не зависит от БД и CLI.
- **data** – репозитории, SQLite. Импортирует domain.
- **cli** – меню, ввод‑вывод. Импортирует domain и data.

## Валидации
1. Обязательное текстовое поле (не пустое после trim)
2. Числовые поля (грузоподъёмность, стоимость, вес и т.д.) > 0

## Тесты
- domain_test – сериализация моделей
- data_test – вставка/чтение из временной БД
- validation_test – проверка валидаторов
